## Snake game

Классическая игра "Змейка", написанная на C++ с использованием библиотеки ncurses для консольного интерфейса.

## Описание игры

Классическая аркадная игра, где вы управляете змейкой, которая должна собирать еду, растущую в длину. Цель - набрать как можно больше очков, избегая столкновений со стенами и собственным телом.

## Особенности

-  Консольный интерфейс с использованием ncurses
-  Система подсчета очков
-  Простое меню управления
-  Плавное движение змейки
-  Визуальное разделение головы и тела змейки

## Установка и запуск

### Предварительные требования

- Компилятор C++ (g++ рекомендован)
- Библиотека ncurses
